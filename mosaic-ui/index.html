A identidade do Mosaic,
pronta para qualquer app.

Teclas que afundam, blocos chapados nas cores do seu wallpaper, pontos que andam atrás de tudo. Um CSS e um JS, sem build e sem dependência nenhuma: copie a pasta e escreva HTML.

Como usar

mosaic.css · mosaic.js

Dois arquivos. O CSS traz tokens, base e componentes em camadas (@layer): qualquer CSS solto do seu app vence o da biblioteca sem !important. O JS registra os elementos e liga os atributos data-mo-*.

As cores leem as variáveis do Matugen. Carregue o colors.css que ele gera e o app inteiro nasce com as cores do wallpaper. Sem ele, vale a paleta menta.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <script src="mosaic-ui/mosaic-inicio.js"></script>
  <link rel="stylesheet" href="mosaic-ui/mosaic.css">
  <link rel="stylesheet" href="~/.config/mosaic/colors.css">
  <script type="module" src="mosaic-ui/mosaic.js"></script>
</head>
<body>
  <button class="mo-tecla mo-tecla--destaque">Olá</button>
</body>
</html>

Cores e tokens

css/tokens.css

Todas as cores vêm do tema: nenhuma cor nova é inventada, as derivadas são misturas das de cima. Troque a paleta no cabeçalho e veja tudo acompanhar, inclusive os pixels. Clique numa cor para copiar o token.

Os quatro tons

Cada nome cai sempre no mesmo tom (tom("firefox")), em qualquer app: o ícone, o cartão, o selo e a etapa de uma coisa têm a mesma cor em todo lugar.

Quatro blocos, um em cada cor. É o logo de todo app Mosaic, o indicador de "trabalhando" (um quarto de volta por vez) e o enfeite dos estados vazios.

Pixels

<mo-pixels> · revelar()

Três ondas lentas, uma por cor do tema, passam por uma grade de pontos; em cada ponto vence a mais forte, como na separação de cores de uma impressão. Tudo é desenhado num Web Worker: o campo nunca trava a página. Passe o mouse.

Símbolos

<mo-simbolo nome>

Desenhados à mão numa grade de 9 × 9 pixels, como os pontos do fundo. Em múltiplos de 9 px cada pixel fica inteiro. Clique num para copiar.

Janela de app

css/app.css

O esqueleto da loja, para todo app ter a mesma "casa": cabeçalho, lateral com a pílula, área de conteúdo com o fundo de pixels e a barra de estado. Esta página é feita com ele. Em tela estreita a lateral vira gaveta.

<div class="mo-app">
  <header class="mo-cabecalho">
    <button class="mo-alternar-lateral" data-mo-gaveta><i></i><i></i><i></i></button>
    <a class="mo-logotipo" href="/"><i class="mo-marca"></i>Galeria</a>
  </header>
  <div class="mo-corpo">
    <mo-pixels class="mo-fundo"></mo-pixels>
    <nav class="mo-lateral">
      <a class="mo-nav-item" href="/" aria-current="page">
        <i class="mo-ponto"></i><span class="mo-nav-texto">Fotos</span><span class="mo-contagem">1.204</span>
      </a>
    </nav>
    <main class="mo-conteudo">…</main>
  </div>
  <footer class="mo-rodape">…</footer>
</div>

Exemplo: calculadora

vitrine/vitrine.js

Um app Mosaic de verdade em 40 linhas de HTML: mo-teclado para a grade de teclas e data-mo-atalho para o teclado físico apertar as teclas da tela. Digite números, + − * /, Enter e Esc.

API JavaScript

mosaic.js
import { avisar, tema, revelar, terminal, abrir, tom } from "./mosaic-ui/mosaic.js";

avisar("Pacote instalado");                          // aviso no canto
const a = avisar("Sincronizando…", { tipo: "trabalhando", duracao: 0 });
a.atualizar("Pronto", { tipo: "ok" });

tema.aplicar(tema.PALETAS.laranja);                  // troca as cores ao vivo
tema.aplicar({ destaque: "#ff8800" });               // só uma cor
await tema.carregar("/colors.css");                  // o arquivo do Matugen
tema.aplicar(null);                                  // volta para o CSS

await revelar(painel, { x, y, trocar: () => render() }); // onda de pixels
terminal("#saida").escrever(":: Sincronizando", "seta");
abrir("#dialogo");                                   // ou data-mo-abrir
tom("firefox");                                      // 0 a 3, sempre o mesmo
